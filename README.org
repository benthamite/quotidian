#+TITLE: quotidian
#+AUTHOR: Pablo Stafforini
#+OPTIONS: toc:2

=quotidian= displays quotations from the Oxford Dictionary of Quotations and
other authoritative sources, either one at a time in a review buffer or in the
echo area while you wait for something else to finish.

The package ships public-domain quotations only. To read material from a
dictionary that is still under copyright, transcribe it into a corpus file of
your own and add that file to ~quotidian-corpus-files~.

* Installation

* Usage

Quotidian reads quotations from the files listed in ~quotidian-corpus-files~,
a list of file paths read in order. The package ships a sample corpus of
public-domain quotations; add a file of your own to the list to include more.

If you edit a corpus file while Emacs is running, call ~quotidian-reload~ to
re-read the files and discard the cached quotations.

** Echo area

Call ~quotidian-echo~ from any hook that fires when you are waiting:

#+begin_src emacs-lisp
(add-hook 'compilation-start-hook (lambda (_process) (quotidian-echo)))
#+end_src

The function never signals an error and never writes to ~*Messages*~, so
it is safe to attach to a hook that fires often.

~quotidian-echo-max-lines~ (default 4) bounds how tall the quotation may
be. Quotations that would need more lines are passed over, so nothing
is ever cut off in the echo area.

* Corpus files

Each corpus file is a JSON array of objects, one per quotation:

#+begin_src json
[
  {
    "text": "The unexamined life is not worth living.",
    "author": "Socrates",
    "source": "Plato, Apology 38a",
    "date": "399 BC",
    "tags": ["philosophy"]
  }
]
#+end_src

| Key      | Required | Meaning                      |
|----------+----------+-------------------------------|
| ~text~   | yes      | The quotation itself          |
| ~author~ | yes      | Who said or wrote it          |
| ~source~ | no       | Where the quotation is from   |
| ~date~   | no       | When it was said or written   |
| ~tags~   | no       | A list of category strings    |

An entry with no ~text~ or no ~author~, or with an empty ~text~, is dropped
with a warning. ~tags~ is parsed and kept on each quotation, but nothing in
the package reads it yet.

A corpus file that cannot be read — missing, a directory, or otherwise
inaccessible — or that is not valid JSON, is skipped with a warning rather
than signaling an error.

A quotation's text and attribution are wrapped to fit the display width.

* Faces

- ~quotidian-quote~ styles the text of a quotation.
- ~quotidian-author~ styles the author, and the date if there is one.
- ~quotidian-source~ styles the source, if there is one.
